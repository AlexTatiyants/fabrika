The control room holds what belongs to you on this machine, rather than to any project or agent. Today that's one setting: how a file opens.

How a file opens

A review can open the real file in your own editor instead of showing it on the page. Pick your editor from the list, or Custom…, and Save. The url template uses {path} for the file's absolute path on this machine and {line} for the first line the change touched. Leave it empty to hide the link.

A file's page in a review then shows Open in your editor →, which opens the file at its first changed line.

Only on this machine

The link is a URL your operating system resolves on the browser's own filesystem, so it's offered only when the console and Fabrika run on the same machine. Reviewing from anywhere else, the file's page says why there is no link.

The setting is stored in factory.yaml: one value for the whole install. The colour scheme, at the end of the top bar, is different: it's kept in this browser only.
