The work map shows what was asked for beside what was built, and how they connect. It's the way into one criterion, or one file.

The map

On the left, Asked for: every acceptance criterion, marked tested, failed test or untested, with the objections that land on it. On the right, Built: every file the run changed, with how many of them need your eyes. The lines between them are links computed from the workers' decisions and the blind tests' tags, never asked of a model. The four counts across the top are the states the work can be in: criteria built and verified, criteria built but not confirmed, criteria nothing built, and files nothing asked for. Press one to draw its links; Show where objections land draws the objections instead.

How much a file needs you

  • novel: a real choice. This is the part a person has to read.
  • conventional: the obvious way, following a convention the repository already had.
  • mechanical: forced by the language or framework; there was no choice to make.
  • generated: the output of a tool or template.

The rapporteur classifies every file; one it leaves out counts as novel, never as safe.

One criterion

↗ open on a criterion pins it at the top with only the code that serves it. Generated, mechanical and conventional code is folded away by default, so what's left is where a choice was made. Its state is one of verified, failing, not settled, no test, no code or you check, and its evidence is one step further: the four kinds, each with what it doesn't prove.

One file

↗ open on a file shows its diff, with what it was written for and every objection about it beside it. If the control room has an editor set and you're on Fabrika's machine, Open in your editor → opens the real file at the first changed line. See The control room.
