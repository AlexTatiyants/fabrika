Agents on the API route need a key for your model provider. Until one is set, nothing can run.

Where it goes

Open the crew page. With no key, its Provider card is open and says nothing can run; once a key is stored, the card folds into one line at the foot of the page, with change and test.

Paste the api key, set the base url if your provider isn't the one shown (any OpenAI-compatible API works), and press Save and test. Saving and testing are one action: Fabrika stores the key, then asks the provider whether it accepts it, and says what it found. Test saved key asks again later.

Where it's kept

In .factory-credentials.json beside factory.yaml, readable only by you (mode 0600), and never sent back to the browser in full. It is kept out of factory.yaml because that file is rewritten on every role edit and shown in this console.

An environment variable of the same name always wins. While one is set, the field is locked; unset it to store a key here instead.

Subscriptions

Agents can also run on a coding assistant's subscription, through its command-line tool. Those sign in through the tool itself, not here. See Routes, models and plan limits.
