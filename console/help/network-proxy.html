Every agent and every check runs in a container with no network of its own. Anything that needs the internet goes through one proxy, which lets public addresses through and blocks this machine and your local network.

Why

A test or an agent that could reach your machine could reach your own dev servers, and a feature's tests would pass or fail against the wrong app. The proxy makes that impossible: agents can reach their model provider and package registries, and nothing private.

Watching it

The crew page has a card for the proxy under the harnesses. It says whether it's running, what it let through in the last day, and anything it blocked, with the container that tried and the reason. Test it starts a throwaway container and checks it can look up an outside name, complete an HTTPS handshake and reach GitHub over SSH. When the proxy is stopped, or its settings changed since it started, the card offers Start it or Restart it; the next build starts it anyway.

When something is blocked

It's almost always a test or an agent reaching for localhost or a fixed port. The fix belongs in the test: read the service's address from the variable Fabrika provides (FACTORY_URL_<SERVICE>), not from a default port.
