Every agent names a route: where its call actually goes. A route is an account, which serves the model and bills for it, and a harness, the program that carries the call.

Two kinds of route

  • An API key to any OpenAI-compatible provider, billed per token. Agents that write files can run in a coding harness: the default route builds OpenHands into an image and runs it in the unit's sealed container. See The provider key.
  • A subscription to a coding assistant, through its command-line tool. It charges by the month, reports turns rather than dollars, and limits use by windows of time. Each call runs in a sealed container of its own.

Routes are defined in factory.yaml; one switched off there isn't shown.

Accounts

One card per account: whether a key is stored or someone is signed in; for a plan, how much of each usage window is used and when it resets, and any credit balance the tool reports; and the last time it refused a call. refusing calls means the tool has turned calls away; Ask now tries again. The key's card has Change key.

Harnesses

One card per program: installed or not, signed in or not, working or not, which agents use it, and the models it offers. A command-line tool signs in through its own browser handshake, which can't happen here, so the card gives you the exact line to run (How to connect) and Check looks again.

Plan meters

The bars move when you use the same plan yourself, not only when Fabrika does. Opening the crew page brings them up to date, and a note under them says how old the reading is. Before a build starts, Fabrika asks whether the plans it needs have room: see Builds that wait for a plan window. A reading of the as-built pauses itself before a window fills.

Choosing a model

In an agent's sheet, every model option names its route, because one model on a subscription and on a key are not the same thing. A route that lets its tool choose offers its own default model; what actually ran is read back afterwards. When a route won't carry a call, see Fallbacks and the independence rule.
